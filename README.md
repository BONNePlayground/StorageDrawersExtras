## Storage Drawers Extra: Reloaded

This is an updated [Storage Drawers Extra](https://www.curseforge.com/minecraft/mc-mods/storage-drawers-extras) addon pack for the Storage Drawers mod, updated and expanded for Minecraft 1.21.1. It adds new wooden drawer styles and crafting recipes using plank blocks from other mods - letting your storage match the unique woods from your favorite modpacks.

#### 🧱 What’s New in the Reloaded Edition

*   Updated for Minecraft 1.21.1
*   Now supports Fabric and NeoForge

Maintains the original aesthetic and compatibility goals
